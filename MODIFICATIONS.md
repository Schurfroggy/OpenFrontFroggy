# OpenFrontFroggy modification notice

OpenFrontFroggy is an unofficial modified version of
[OpenFront](https://github.com/openfrontio/OpenFrontIO). It is maintained by
Schurfroggy and is not an official OpenFront release or endorsed by the
OpenFront team.

The local modification work started from upstream commit
`e02eeba66b4801ebae0b686e1b0e4bc03fbf3654`.

Major changes include:

- a self-hosted friends-server mode;
- Simplified Chinese localization and language switching;
- local username/password accounts and administrator-assisted password reset;
- local achievements tied to accounts;
- rotating map recommendations and streamlined game configuration;
- host-controlled multiplayer team assignment; and
- removal or hiding of official-service features that do not apply to a
  friends server.
