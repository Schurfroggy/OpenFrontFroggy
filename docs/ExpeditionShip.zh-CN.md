# 远航船

## 规则与操作

仅在战争迷雾模式出现。默认 N 键（支持自定义），或点击单位栏最右侧的远航船按钮，然后点击目标直接出航。按钮位于氢弹之后，启用 MIRV 时位于 MIRV 之后；复用标准单位栏样式，左上角为快捷键，图标右侧为已有数量，不显示在役上限。单位功能和当前价格统一通过标准悬浮提示展示，不再提供右侧派遣面板、选港和确认步骤。点击前可用 Esc、右键或再次按 N 取消。未知目标不显示地形、可达性、真实绕行路线或精确 ETA。

出发港由模拟端自动选取：在自己的已建成、未标记拆除且有相邻水面的港口中，选择到目标曼哈顿距离最近的一个；距离相同时按港口 ID 决定。陆地、封闭水域等目标仍可选，使用原有的尽量接近目标规则。

不限制在役数量。按本局累计成功派出的数量计价：前 5 艘每艘 150,000 黄金，第 6 艘起每艘 300,000；沉没后不恢复低价，存档继续保留累计数量。支持原有无限黄金设置。250 生命，无武器、不载兵、不占地。正常航行每 4 tick 前进 5 个路径格，约为军舰的 1.25 倍。复用运输船船体，以青色标识区分，工具栏使用独立帆船图标。

选点时在迷雾上方显示预计出发港至目标的虚线，以及高对比圆环准星。镜头缩放和平移时保持与鼠标位置对齐。虚线只示意方向，不计算或展示隐藏地形上的真实绕行路线。

成功出航后，在原定目标处持续显示自己的黄色旗帜，位于迷雾上方，不提供当地视野。旗帜随镜头平移缩放保持定位，取消其他选点不会清除；船只抵达实际终点（不可达目标使用替代终点）或沉没后移除对应旗帜。初次航行因寻路失败而等待时保留旗帜，完成停留后自主探索遇阻不会重新显示旗帜。

视野最高亮度 10，半径 48 格，圆形衰减；直接盟友/同队共享，叠加取最大值。停留侦察期间，该船实际视野内有陆地领土的国家及其直接盟友/同队，也共享该船的局部视野，并获得船主国家的信息。以实际停靠位置判断，不以原定目标判断。停止侦察、失去当地领土或船沉没后收回额外共享；正常视野仍按原有规则保留。

## 航行状态

1. **远航中**：复用水路寻路，目标在同一连通海域时直接前往。陆地或不同连通海域的目标，选择当前海域中尽量接近的位置，兼顾离出发位置的距离。实际路径设置绕行上限；粗分辨率路线遇到沿岸陆地时，通过有节点数和距离上限的局部水域 BFS 修复。
2. **停留侦察**：抵达实际终点后停留 600 个模拟 tick（1 分钟游戏时间），不追击敌船。到达替代终点才提示“已到达本海域可接近的位置”。
3. **自主探索**：从当前位置生成候选航点，优先避开最近经过的区域，再以带种子的随机数打破相近评分。航点不围绕原始目标设置固定巡逻圈，小海域适当缩短单段距离。最近行程记录只用于导航，不会留下玩家永久视野，也不根据隐藏国家、单位或全局情报选择航点。
4. **原地等待**：没有合适路线时保持现有视野，间隔一段模拟时间尝试新航点；等待提示不重复刷屏。

出港一定距离后发现海岸/新国家会产生通知，原航程照常继续。到达、发现与等待状态通过原有事件栏通知；不再常驻显示额外船只列表面板，不提供改目标、召回、手动销毁命令。军舰框选/全选不包含远航船，原有移动、运输船召回、删除指令不能控制它。可被敌方军舰击沉，击沉后重新计算阶梯价格。

## 代码接入与存档

- 独立 `expedition` 意图仅携带目标格，由模拟端自动选择港口，不复用普通建造/军舰移动意图。模拟端重新检查模式、玩家、港口归属及建设状态、当前阶梯费用、坐标和禁用设置。
- 新单位类型及意图判别值追加到既有序列末尾，避免改变已有二进制协议标签顺序。
- 独立 Execution 持有路径、进度、近期行程和随机数状态；单位更新提供只读航行状态。Execution 注册快照，Unit 快照升级版本并保留旧版本迁移。
- 客户端只持有目标选择状态；点击后控制权交给确定性模拟。选点期间阻止普通攻击、舰队移动与菜单点击误触。

## 验证范围

真实地图测试覆盖阶梯费用、同 tick 连续派遣、沉没和读档后保留高价、双向视野共享与收回、不可达陆地目标、水面移动、600 tick 停留、自主探索、伪造控制命令、军舰击沉与快照恢复后的相同航程。界面测试覆盖目标旗帜定位与生命周期、虚线路径与准星、取消清理、N 键直接派遣、点击事件拦截、标准单位栏的顺序/尺寸/价格提示和普通模式隔离。

本次调整补充自动选港、拆除/内陆港口过滤、单次点击消费与标准单位栏的回归测试；构建和相关测试结果见本次交付。
