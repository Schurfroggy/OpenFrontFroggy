# 战争迷雾实施方案

## 已确认规则

- 可选房间/单人模式，默认关闭。与水核弹、末日时钟及加时领土压缩互斥；普通地图、队伍、经济和单位开关保留。
- 亮度 0–16；本国领土基准 10，设施和军舰基准 16。叠加取最大值，亮度大于 0 可见。
- 领土向外视野随面积分档缓慢增加并封顶；设施与军舰使用固定半径。只共享直接盟友/同队成员自身产生的视野，不传递盟友的盟友视野。
- 当前视野触及国家领土即可查看现有完整国家面板；不揭示全境或雾外设施位置。失去接触关闭面板；排行榜不提供隐藏情报。
- 雾外格子禁止新攻击、登陆、建造和目标交互。自己的军舰可向未知坐标移动；核武器可按坐标盲投。已开始的模拟继续。
- 防空图标/范围和核弹预览仅使用可见防空；实际拦截保持原样。准备发射时，核弹轨迹和爆炸范围预览绘制于迷雾上方，允许在未知区域看清瞄准提示；不显示隐藏防空、敌方单位或实际飞行中的隐藏导弹。战争视图与核攻击者全境高亮关闭。
- 核弹实际爆炸产生全球公开视野，被拦截不产生；实际荒地格子提供亮度 16 和少量外围，固定持续 30 秒（300 个模拟 tick），不提供调节项。逐格重新占领立即移除对应光源，失效后不因再次弃地而恢复。重叠光源保留各自到期时间。
- AI 在迷雾模式下使用局部情报、保守远征、可见核打击、主动远航与更高结盟意愿；普通模式不受影响。详见 [迷雾模式 AI](FogOfWarAI.zh-CN.md)。
- 出生阶段展示地图用于选择出生点；本版观察者/回放维持全局视角。客户端仍运行全图模拟，此模式不提供对修改客户端的防作弊隔离。

## 顺序与接入点

1. **配置**：Schemas 添加 fogOfWar 开关；统一互斥规范化，用于服务端配置更新和核心 Config 防御；HostLobbyModal/SinglePlayerModal 加开关、互斥状态和重置；英文翻译与房间摘要。
2. **核心视野**：新增 FogOfWar 纯计算模块，整数多源距离传播，按领土半径分组；视野图与可查询国家集合。GameRunner 向本地客户端输出亮度，按 tick 缓存供人类指令检查复用。
3. **核爆状态**：GameImpl 保存荒地光源及到期 tick；爆炸登记，conquer 时撤销；快照版本升级及旧版迁移。公共视野是持久模拟状态，亮度是可重建派生数据。
4. **渲染**：独立 WebGL 迷雾 pass，地图空间亮度纹理，合成于世界内容之上；玩家自己的核弹轨迹和爆炸范围瞄准预览在迷雾之后绘制。单位/设施及名字按可见性过滤。GameView 提供统一 isTileVisible/canViewPlayer/isUnitVisible，视野变化强制刷新静态设施。
5. **权限**：地图菜单、悬停、国家面板、排行榜、建造预览统一查询权限；核心 Executor 拦截人类雾外新操作，保留军舰移动和盲投核弹。异步返回和持续打开的面板重复校验。
6. **防空与战争视图**：防空预览过滤；模式选择器隐藏战争视图，控制器禁用战线及核攻击者高亮。
7. **验证**：核心亮度/面积上限/直接联盟/接触丢失；核爆到期/逐格修复/重叠/快照；权限例外与普通模式 AI 不变；配置互斥；TypeScript、相关 Vitest、格式及 lint。记录实际结果和限制。

## 初始调参

领土外扩距离 16/24/32/40 格（面积阈值 0/10k/50k/200k），单位外扩距离 48 格，核爆荒地外围 6 格。距离采用整数平方欧氏距离变换（圆形边界），边缘亮度向上取整，0 是明确的不可见边界。参数集中定义，后续根据实战反馈调整。

## 配置与代码结构

单人模式和房间设置中选择 `Fog of War (exclusive mode)`。开启后核爆公开视野固定为 30 秒，并隐藏水核弹、末日时钟、延长赛控件。关闭迷雾不会自动恢复此前关闭的特殊模式。

```ts
fogOfWar: {
  enabled: true;
}
```

- `game/SpecialModes.ts`：统一规范化互斥模式，在服务端建房、配置更新和核心 Config 中兜底；即使外部传入冲突组合，迷雾优先。
- `game/FogOfWar.ts`：面积分档、整数距离场、直接友方光源合并、当前国家接触集合、人类指令校验。按游戏和观察者缓存同一 tick 的结果；AI 内部决策通过 `FogOfWarIntel.ts` 过滤情报和目标。
- `GameImpl`：持久保存 `tile → expiryTick` 公共核爆光源，同一格重叠爆炸取最新到期时间。重新占领删除光源，重新弃地不恢复；每个模拟 tick 确定性清理过期项。
- `NukeExecution`：只在实际落地并产生荒地后登记光源；拦截路径不登记。
- `GameRunner → Worker → GameView → FrameData → FogOfWarPass`：每 tick 输出观察者亮度图；传输副本以免分离核心缓存的 ArrayBuffer。GUI 保留完整模拟镜像供国家面板使用，只过滤显示与操作权限。
- `GameView`：统一 `isTileVisible`、`isUnitVisible`、`canViewPlayer`；保留全国数值，过滤空间单位、名称与事件。退出受限视角时也刷新设施，避免观战遗留旧缓存。
- `PlayerInfoOverlay`、`PlayerPanel`、`MainRadialMenu`：首次打开、刷新、异步返回和视野失效时重新校验。失去当前接触后撤销实时查询入口；不尝试让玩家忘记已经看到的信息。
- `PlayerStats`、`TeamStats`：只为当前可查询国家生成行/团队汇总；不通过排名暴露雾外国家数值。
- `BuildPreviewController`：过滤不可见防空设施；普通雾外建造/登陆无预览，核武器保留按坐标发射。
- `WarFrontsController`、`MapViewSelector`、`MapRenderer`：禁用战争方向、战争视图入口和核攻击者全境高亮。
- `GameSnapshot`：版本 1 → 2，旧快照迁移为空公共光源集合。回放编码丢弃观察者亮度，回放保留全局观战视角。

## 本版限制

- AI 已在迷雾模式下适配情报权限、结盟、远航和军舰索敌；长期平衡仍需实际对局验证。
- 设施、军舰视野与领土半径是首轮参数，尚未进行多人长期平衡测试或最大规模地图压力测试。
- 客户端完整模拟及全局回放不提供对修改客户端的隐藏信息防作弊保证。

## 试玩反馈修订

- 核爆公开视野时长固定为 300 个 tick（30 秒），移除配置字段、表单控件、事件、状态和翻译。修复荒地仍会提前撤销对应光源。
- 排行榜在迷雾模式下按模拟 tick 刷新，避免一秒节流保留已失去接触的旧行。活跃玩家遇到缺失/延迟视野数据时不会自动获得全国情报；已有亮度图在缺失更新中保留。排名在已知国家集合内重新排序，隐藏国家不参与行、名次和团队总数。
- 圆形视野使用精确平方欧氏距离变换，按最近光源计算。亮度衰减使用整数定点平方根查表，不使用平台相关的浮点平方根；开销随地图格数线性增长，不随重叠军舰数量逐艘扫描圆盘。
- 渐变只在 GPU 显示层进行：R8 线性采样、四点空间平滑和 100 毫秒帧间过渡。当前真实亮度为 0 的格子始终完全遮挡，失去视野即时隐藏，不因动画保留过期情报。无需多次全屏模糊绘制；比原版增加一张每格 1 字节的 GPU 亮度纹理。
- 本机热身后距离场基准（单个字段，4 次采样中位数）：1024²/1 光源约 0.59ms，1024²/100 光源约 7.70ms，2048²/100 光源约 16.12ms。这不是整局帧耗时，也不代表其他设备或 GPU 上的性能保证。

- 本轮修订验证：17 个相关测试文件、159 项测试全部通过；开发构建、TypeScript、Oxlint、ESLint、Prettier 与 diff 空白检查通过。已在实际对局中验证圆形单位光源、平滑渐变、排行榜接触范围及固定时间设置界面。

## 出生点选择与中文设置修订

- 简体中文设置开关显示“迷雾模式”，繁体中文显示“迷霧模式”；单人设置、房间设置及设置摘要共用翻译键。
- 领土面积影响外围视野的功能原已实现：不足 1 万格为 16 格，达到 1 万/5 万/20 万格分别为 24/32/40 格。设施和军舰固定 48 格，可能掩盖附近领土视野增长的差别。新增真实地图测试，在边界不变的条件下扩充后方领土，确认跨档后原先不可见的外围格子变为可见。
- 迷雾对局选择出生点时，渲染使用全图亮度 5；保留全地图选点操作。亮度图缓存复用，只用于显示，不作为国家情报或操作权限的来源。出生阶段结束后使用正常视野；普通模式、回放和无本地玩家 ID 的观察视角保持原有显示。
- 本轮验证：10 个相关测试文件、66 项测试通过，开发构建及 TypeScript 检查通过，相关代码 Oxlint、ESLint 和 Prettier 检查通过。浏览器实测确认中文开关、暗光地图可选择出生点，以及出生后恢复局部视野。

## 流动云雾第一版

- 未知区域使用低对比度深蓝灰云纹；两层纹理大小和方向不同，随渲染时间缓慢漂移。纹理固定于地图坐标，随拖动、缩放一起移动，原有亮度渐变保留。
- 只改变迷雾颜色，不改变透明度规则或视野判断：当前亮度为零的格子仍以完全不透明的云雾覆盖，不会因云纹变亮而显示下方地图。领土、盟友、军舰和核爆视野规则保持原样。
- 在既有迷雾通道内增加两次纹理采样，没有增加绘制通道或每帧 CPU 地图计算。128×128 R8 可平铺云纹在初始化时生成，含 mipmap 约占 22 KB GPU 内存。颜色、强度、尺寸与速度集中在 render-settings.json，不新增玩家设置项。
- 验证：5 个测试文件共 76 项相关测试、开发构建、TypeScript、Oxlint 和 ESLint 通过；实际单人对局确认出生阶段、正常视野及缩放后的云纹显示。纹理生成热身后本机中位耗时约 0.34ms，只在初始化时执行；这不代表整局渲染耗时，未做低端设备 GPU 压力测试。

### 缩小视图的网格规律修正

- 第一版的方格插值噪声与较短的平铺周期，在远景下容易形成规则排列。改用白噪声经过多尺度环绕平滑生成随机云团，两通道分别生成，去掉粗方格噪声的结构。
- 平铺周期扩大至原来的四倍，并以另一层低频噪声轻微扭曲采样坐标；两层云纹使用不同通道、旋转、尺度与漂移方向，减弱重复图案，保留地图坐标锚定。
- 当前使用 256×256 RG8 纹理，含 mipmap 约占 171 KB；每个片元三次云纹采样，仍在原有一次迷雾绘制中完成。替代上一版 128×128 R8 / 两次采样的方案。生成只在初始化时执行，本机冷启动单次约 46ms；未进行设备间性能对比。
- 76 项相关测试、开发构建、TypeScript、Oxlint 和 ESLint 检查通过；在标准世界地图实际对局中检查近景和全图远景。
