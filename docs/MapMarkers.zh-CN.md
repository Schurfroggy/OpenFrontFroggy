# 地图标记（第一版）

- 开战并选定出生地点后，在地图上单击鼠标中键放置标记；再次中键点击自己的旗帜可删除。中键拖动、取消点击和窗口失焦不会放置标记。
- 每人最多保留 3 个标记。第四个标记自动替换本人最早的标记，不出现上限提示，也不影响队友的标记。
- 原有自动升级最近建筑功能改为 **Shift＋中键**；帮助面板已更新。
- 标记在地图和底部进攻卡片上方显示。点击列表文字定位地图；本人标记的 × 会删除并同步给队友，队友标记的 × 只在自己当前界面隐藏。
- 地图标记使用玩家国旗与旗杆组合，旗面 52×34 屏幕像素、旗杆约 70 像素，缩放地图不改变其大小；没有国旗时使用玩家颜色与名字缩写，图片加载失败时同样回退。远航船的目标符号保持独立。
- 新插旗时，落点播放约 0.7 秒的小范围扩散圆环；开启系统“减少动态效果”时省略动画。团队内其他人类玩家收到顶部通报“某某将目标设定为：地点”，持续 3 秒；连续标记更新为最新一条。重连恢复、删除和地名变化不重复触发通报或动画。
- 地点固定在格子上，名称随当前归属变化：国家／部落名称、荒地、海洋。迷雾内未获得视野的地点显示“未知区域”，不会通过标记获得视野或隐藏国家信息。
- 多人模式只向同一固定团队发送标记；自由混战仅本人可见，外交盟友不共享。旁观者与录像不提供标记操作。
- 标记不自动过期，短暂断线后重连会恢复。正常退出对局清除本人标记；服务器结束并释放对局时不再保留。

## 实现与验证

标记使用独立的联机消息，由服务端根据连接身份认定创建者和团队，再向允许接收的连接发送快照。客户端不能指定其他创建者，也不能删除队友标记。每人三个的限制由服务端执行。

标记不进入模拟回合、状态哈希或对局录像，避免改变游戏同步结果。单人模式使用本地同样的容量规则。名称在客户端按当前视野和领土归属解析；地图缩放时只更新旗帜位置，底部列表内容变化时才更新界面。

地图尺寸从地图清单读取，同时支持本地资源和生产环境的哈希资源路径；地图信息按地图缓存。公共小地图的国家数量与实际模拟规则保持一致，用于还原团队分配。

测试覆盖容量替换、创建者权限、真实联机消息、团队隔离、重连恢复、迷雾名称保护、地名变化、底部定位／删除、单人模式及鼠标按键。
