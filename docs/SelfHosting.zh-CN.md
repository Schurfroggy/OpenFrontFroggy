# OpenFront 朋友联机自托管

这个模式面向小范围、受信任的朋友联机。浏览器、房间协调服务和游戏 Worker 都在你自己的电脑上运行，不依赖 OpenFront 官方账号、服务器列表或公共社区服务。

## 快速启动

先安装依赖，然后在项目根目录运行：

```bash
npm run self-host
```

本机打开：

```text
http://localhost:9000
```

同一局域网内的朋友打开：

```text
http://你的局域网IP:9000
```

例如主机地址是 `192.168.1.20`，朋友就访问 `http://192.168.1.20:9000`。macOS 或 Windows 第一次启动时若出现防火墙提示，需要允许 Node.js 接受局域网连接。

进入页面后，由一人点击“创建游戏”，设置地图和规则；其他人可以直接打开房主复制的邀请链接，也可以点击“加入游戏”并输入房间代码。

## 端口与网络

- `9000` 是浏览器访问入口，也是局域网中唯一需要开放的端口。
- `3000` 是本机协调服务端口。
- `3001`、`3002` 是本机游戏 Worker 端口。
- Vite 会把 HTTP 和 WebSocket 请求从 `9000` 转发到内部服务，因此不要把 `3000`—`3002` 直接暴露到公网。

如果朋友不在同一局域网，建议使用支持 WebSocket 的 HTTPS 反向代理或可信隧道，把一个 HTTPS 域名转发到本机 `9000`。直接在路由器上把开发服务器裸露到公网不适合长期使用。

## 自托管模式保留的内容

- 单人游戏与教程
- 创建私人多人房间
- 通过链接或房间代码加入
- 房主修改游戏规则、开始游戏、踢出玩家
- 旁观、聊天、回放等由本地游戏服务器提供的功能
- 英语与简体中文切换
- 本地用户名和密码账户、个人资料改名与地图成就

## 自托管模式关闭的内容

- OpenFront 官方登录与官方账号资料
- 官方公共房间列表和自动生成的公开对局
- 排位和匹配队列
- 商店、库存、订阅和奖励
- 排行榜、公会、好友资料和官方动态
- 广告、营销弹窗、统计脚本与第三方游戏平台 SDK
- 官方对局归档上传与官方单人心跳

这些界面入口会在 `SELF_HOSTED=true` 时隐藏，后台也不会轮询相应的官方接口。

## 本地账户

首次打开自托管页面时默认以游客身份进入。游客仍可进行单人游戏、创建房间和加入房间，但不会读取或获得永久成就。首页只显示当前名字；注册、登录、查看资料和修改名字统一放在顶部的“我的”页面。

注册账户需要 3—20 个字符的用户名和至少 8 个字符的密码。用户名忽略大小写、全角/半角差异与多余空格；密码只以加盐哈希保存在本地 SQLite 中。浏览器登录状态默认保持 30 天。

忘记密码时，普通玩家可在登录页提交重置申请。申请会保存在 SQLite 中，浏览器保存一次性恢复凭证；用户可以关闭页面，稍后回到“我的”继续检查状态。管理员在“管理”页面批准后，用户有一小时设置新密码。完成重置会注销该账户的所有旧会话。待批准申请默认在 24 小时后过期。

第一个完成注册的账户会被标记为管理员，之后的账户默认为普通玩家。也可以在账户注册前，通过逗号分隔的 `SELF_HOSTED_ADMIN_USERS` 环境变量预先指定管理员用户名，例如：

```bash
SELF_HOSTED_ADMIN_USERS=Froggy,Alice npm run self-host
```

管理员会在顶部看到“管理”标签，可以查看所有注册账户、有效会话数量以及待处理的密码重置申请。管理员只能批准或拒绝申请，无法读取用户原密码；数据库中只保存不可逆的密码哈希。

管理员账户不能通过网页提交审批申请，以免管理员批准自己的密码重置。管理员忘记密码时，必须在运行服务器的电脑上执行：

```bash
npm run account:reset -- Froggy
```

命令会生成并只在本地终端显示一次临时密码，同时注销该账户的旧会话。管理员使用临时密码登录后，应立即在“我的”页面修改密码。

## 本地成就数据库

登录账户在单人或多人胜利后，服务器会按“账户 ID + 地图 + 难度”记录成就。地图选择界面会用对应难度的骷髅图标展示该账户在每张地图上的最高通关难度；游客不会读取或写入这些记录。

成就默认保存在项目根目录的 `data/self-hosted.sqlite`。这是一个 SQLite 单文件数据库，不需要另行安装数据库服务。备份或迁移朋友服时，请一并复制这个文件；服务器运行期间备份时，也应同时保留同目录下可能出现的 `-wal` 和 `-shm` 文件，或者先停止服务器再复制主数据库文件。

可以通过环境变量 `SELF_HOSTED_DB_PATH` 指定其他保存位置。部署在容器平台时，应将该路径放在持久化磁盘上，否则容器重建会清除成就。

房间邀请链接相当于加入凭证，请只发给受信任的朋友。该模式没有面向公共运营所需的账号审核、反作弊、完整限流和管理后台，因此不应当直接作为公开游戏平台部署。

## 恢复普通开发模式

普通开发模式仍然使用原来的命令：

```bash
npm run dev
```

只有 `npm run self-host` 会设置 `SELF_HOSTED=true` 并启用上述精简行为。
