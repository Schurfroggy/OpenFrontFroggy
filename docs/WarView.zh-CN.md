# 战争视图：箭头与前线数据

箭头从尾部到头部平滑增加不透明度，长度前 80% 完成渐变，最后 20% 保持头部不透明度。填色和描边一起渐变，并与总透明度、出现／消失动画及撤回呼吸效果相乘。

战争箭头采用独立设计的连续尖矛轮廓：尾宽颈窄、V 形内凹尾端、后掠尖角。整根箭头按同一个完整凹多边形轮廓计算填色，避免头身连接处的接缝；尾端沿三角缺口向箭身内部切入，使两侧形成尖角。缺口的两条斜边不绘制白色描边，其余轮廓保留描边。当前根据模拟中的实际接触边界和近期占领方向绘制直箭头。

参数入口：`src/client/render/gl/render-settings.json` 的 `warArrows`。修改后重新加载游戏。长度与宽度是地图格单位，透明度为 0～1，时间为毫秒。

| 参数                   | 默认 | 含义                                                         |
| ---------------------- | ---- | ------------------------------------------------------------ |
| tailLengthTiles        | 12   | 前线后方期望长度                                             |
| tipLengthTiles         | 16   | 前线前方期望长度                                             |
| widthStartTiles        | 2.4  | 箭身尾部半宽                                                 |
| widthTipTiles          | 0.9  | 箭身颈部半宽                                                 |
| headWidthTiles         | 3.4  | 肩部最大半宽                                                 |
| headLenTiles           | 7    | 尖端区域长度，短箭头会自动限制                               |
| headSweepRatio         | 0.4  | 头部凹口前移比例，范围 0.1～0.8；默认两侧尖角约 25°          |
| directionOffsetDegrees | 0    | 在测得方向上顺时针旋转的角度；旋转后仍检查地形               |
| outlineTiles           | 0.28 | 向内描边宽度                                                 |
| alpha                  | 1    | 总透明度                                                     |
| tailNotchRatio         | 1.25 | 尾部三角缺口深度与尾部半宽之比；深度最多为箭身连接位置的一半 |
| tailOpacity            | 0.18 | 尾部不透明度倍率，范围 0～headOpacity                        |
| headOpacity            | 1    | 头部不透明度倍率，范围 0～1                                  |
| revealMs               | 480  | 从尾部向尖端显现的时间                                       |
| smoothingMs            | 240  | 移动平滑时间常数                                             |
| lingerMs               | 800  | 攻击消失后保留的时间                                         |
| fadeOutMs              | 900  | 随后淡出的时间                                               |
| jumpDistanceTiles      | 40   | 超过此距离，旧箭头淡出，新箭头重新显现                       |
| refreshTicks           | 4    | 前线查询间隔，正常速度约 400 ms                              |
| blinkPeriodMs          | 900  | 撤回时的呼吸周期                                             |

长度和宽度仍受国家面积倍率影响。最终长度在缩放、旋转后从近到远检查地图、陆地、不可通行地形和归属；宽度按完整轮廓的局部空间逐步缩小。非常狭窄、无法放下箭头的前线会隐藏。插值跨越海岸或障碍时重新显现，避免箭头穿越无效地形。

查询按进攻方轮转，每轮最多 10 个，过期数据在 5 秒后停止使用。动画在现有 WebGL 帧循环执行，RPC 返回次数不影响动画时长。关闭战争视图时清理动画状态，过期查询不能恢复旧视图。

## 第二阶段：真实前线与稳定身份

- 战争视图通过 `attackClusteredPositions(undefined, true)` 请求额外的 `fronts` 数据；普通攻击兵力标签仍使用原来的聚类位置，不增加历史采集成本。
- 模拟端从攻击候选边界中筛选目标方拥有、可通行且与进攻方陆地四向接壤的地块，按八邻域分成独立战线。每条战线选一个真实接触地块作为锚点，不使用可能落在海里的平均坐标。小战线也保留，每次最多返回 6 条；客户端同一进攻方向最多显示 6 条。
- 方向优先使用该锚点附近 12 格内、最近 30 tick（正常速度约 3 秒）的实际占领方向，按距离和时间衰减。历史方向必须与当前局部边界方向相符；证据不足、过期或方向相反时，使用附近 6 格内的实际接触边法线。对称包围时选真实接触边，无有效接触时不显示，不再使用国家建筑中心或随机偏转推测。
- 占领方向在地块易主前，从进攻方相邻地块指向被占领地块计算。每次攻击最多缓存 256 个样本，仅在查询战争视图后开启采集；100 tick 未再次查询就停止采集。缓存不写入存档，不参与战斗、同步哈希或随机数；读档后先使用真实边界方向，再逐步积累历史。
- 箭头身份由国家对、位置和方向匹配，不绑定攻击 ID 或聚类排序。增兵换 ID、大小排序变化时保持身份；分裂时只允许一个分支继承旧身份，其余重新出现。相距 4 格内、方向相近且中间没有海水、障碍或第三方领土的重复攻击合并显示。不同战线分别保留撤回状态。
- 身份匹配距离使用 `jumpDistanceTiles`；匹配要求方向同向且两锚点之间可通行。旧身份保留时间为 `lingerMs + fadeOutMs + refreshTicks × 100` 毫秒。插值和最终轮廓均检查可通行陆地及交战双方归属，不能侵入第三方领土。

战争迷雾对局仍禁用战争视图及其前线查询。箭头表示当前局部推进趋势，不代表实体军队的精确行军路线。曲线路径、对一条很长的连通战线进一步分段，以及更精细的分裂／合并拓扑跟踪留待后续阶段。
